One word, and nothing else: the single word Grandma would text about AI.

## The word

**tinman**

Grandma has never once said "artificial intelligence". She has, however, met
a robot — and in her world there is exactly one name for a walking, talking
metal man: the Tinman, straight out of Oz. Warm, a little baffled, and
instantly readable: that is what she texts.

## Run it

```sh
python3 main.py
```

It writes `tinman` to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`)
and prints the same word to stdout.
